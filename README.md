# Maul3D

A 3D rigid body physics engine for sandbox games. Written in C17 with a plain C API. MIT licensed.

Design goals: cross-platform determinism, snapshot/rollback as a core operation, and destructible worlds.

No code yet — the design is being finalized first. The solver core is being validated in [Maul2D](https://github.com/siracozmen01/Maul2D) before anything lands here.
